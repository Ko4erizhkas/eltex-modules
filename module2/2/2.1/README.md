# 2.1 — Телефонная книга на массиве

Первая версия телефонной книги: контакты лежат в массиве указателей
фиксированного размера внутри структуры `Phonebook`.

## Сборка и запуск

```
make
./pb.exe
```

Вывод в консоли — UTF-8, `main.c` переключает кодовые страницы через
`SetConsoleCP`/`SetConsoleOutputCP`, поэтому программа привязана к Windows.
При старте книга заполняется восемью тестовыми контактами (`fillTestData`).

## Файлы

| Файл | Назначение |
|---|---|
| `phoneBook.h` | Типы данных и прототипы |
| `phoneBook.c` | Хранение, ввод/вывод, редактирование, меню |
| `main.c` | Точка входа, настройка кодировки консоли |
| `tests/` | Юнит-тесты на Unity |

## Модель данных

```
Phonebook
  ├── int countContacts
  └── Contact* contacts[8]      — указатели, каждый контакт в своём malloc
        └── Contact
              ├── Numbers phonenumber[4]
              └── Social  social[4]
```

Контакты хранятся по указателю, поэтому добавление сводится к записи указателя
в свободную ячейку, а удаление — к `free` плюс сдвиг хвоста через `memmove`.
Порядок контактов — порядок добавления, сортировки нет.

| Константа | Значение | Что ограничивает |
|---|---|---|
| `MAX_SIZE` | 128 | длина Ф.И.О., номера, ника, названия соцсети |
| `MAX_SIZE_LINK` | 512 | длина ссылки на профиль |
| `MAX_COUNT` | 4 | номеров и соцсетей на контакт |
| `MAX_COUNT_CONTACTS` | 8 | контактов в книге |

## Меню

| Пункт | Действие |
|---|---|
| 1 | Добавить контакт |
| 2 | Удалить контакт по номеру |
| 3 | Изменить контакт: Ф.И.О., соцсети, номера |
| 4 | Вывести все контакты |
| 0 | Выход |

## Примеры работы

### Книга заполнена: сначала удалить, потом добавить

При старте все восемь мест заняты тестовыми контактами, поэтому добавление
сразу отвергается — сначала нужно освободить место.

```
1. Добавить контакт
2. Удалить контакт
3. Изменить контакт
4. Вывести все контакты
0. Выйти
Выберите действие: 1
Телефонная книга заполнена.
Добавление номера невозможно.
Удалите ненужный контакт

Выберите действие: 2

-------------------
Какой контакт хотите удалить?: 3

Выберите действие: 1

Введите Ф.И.О
Фамилия - обязательно: Абрамов

Имя - обязательно: Пётр

Отчество: Сергеевич
Введите номер телефона #1 (пусто - завершить) (максимум 4 номера): +7-900-123-45-67
Введите номер телефона #2 (пусто - завершить) (максимум 4 номера):
Соцсеть #1 - платформа (пусто - завершить): Telegram

Имя пользователя - обязательно: abramov

Ссылка на профиль - обязательно: https://t.me/abramov
Соцсеть #2 - платформа (пусто - завершить):
```

Пустая строка завершает ввод номеров и соцсетей. Новый контакт встаёт в конец
массива: порядок здесь — порядок добавления, сортировки нет.

### Правка Ф.И.О.

```
Выберите действие: 3

-------------------
Список контактов:
... вывод всех контактов ...

-------------------
Выберите контакт: 1

Список доступных изменений:
1. Изменить Ф.И.О
2. Изменить соц сети
3. Удалить соц сети
4. Изменить номер телефона
5. Удалить номер телефона
Выберите действие 1

Измениние Ф.И.О (пусто - оставить без изменений)
Имя [Иван]:
Фамилия [Иванов]: Яковлев
Отчество [Иванович]: Петрович
```

Пустой ввод оставляет поле как было — здесь изменились только фамилия и
отчество. Позиция контакта в книге не меняется.

## Тесты

```
cd tests
make test
```

Функции в `phoneBook.c` объявлены `static`, поэтому тест включает сам `.c`
целиком — так `static` перестаёт мешать. Ввод подменяется файлом-фикстурой
через `freopen` на `stdin`, вывод программы глушится, чтобы отчёт Unity
оставался читаемым.

Покрыты добавление и удаление контактов, номеров и соцсетей, ввод Ф.И.О.,
сценарий добавления целиком и заполнение тестовыми данными.

Четыре теста намеренно помечены `TEST_IGNORE` — они фиксируют найденные
в коде проблемы, запуск которых уронил бы весь прогон:

- `addContactInPhonebook` не проверяет `countContacts < MAX_COUNT_CONTACTS`
  и пишет за границу массива на девятом контакте — в самой программе от этого
  спасает только проверка в меню, а не сама функция;
- `deleteContact` не проверяет индекс — `free` по мусорному указателю;
- проверка границы в `deleteNumber`/`deleteSocial`/`editNumber`/`editSocial`
  написана как `index > count` вместо `index >= count`, из-за чего размер
  для `memmove` уходит в переполнение `size_t`;
- `editNumber` печатает структуру `Numbers` по `%s`.

Ограничение размера книги снято в задании 4.1, где массив заменён списком.
