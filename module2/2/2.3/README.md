# 2.3 — Калькулятор на массиве указателей на функции

Тот же калькулятор, что и в 2.2, но `switch` заменён массивом указателей
на функции.

## Сборка и запуск

```
make
./calc.exe
```

## Файлы

| Файл | Назначение |
|---|---|
| `calc.h` | Прототипы операций и меню |
| `calc.c` | Операции и цикл интерфейса |
| `main.c` | Точка входа, настройка кодировки консоли |
| `tests/` | Юнит-тесты на Unity |

## Что изменилось относительно 2.2

Вместо разбора пункта меню в `switch` операции лежат в массиве:

```c
double (*operations[4])(double, double) = { sum, sub, mult, divide };
...
printf("Результат: %f\n", operations[choice - 1](a, b));
```

Отсюда два следствия:

- пункт меню превращается в индекс, границы проверяются один раз через
  `sizeof(operations) / sizeof(operations[0])` — добавление операции не требует
  править диспетчеризацию;
- проверка деления на ноль из 2.2 исчезла: единой точки «перед вызовом
  операции» больше нет, и `divide` отдаёт бесконечность по IEEE-754.

Именно этот массив в задании 6.3 заменяется таблицей операций, собранной из
динамических библиотек при запуске.

## Тесты

```
cd tests
make test
```

Операции объявлены `static`, поэтому тест включает `calc.c` целиком.
`stdin` подменяется файлом-фикстурой, `stdout` перехватывается в файл,
отчёт Unity уводится в `stderr`.

Покрыты арифметика всех операций, отдельно — диспетчеризация через массив
(каждый пункт меню обязан вызвать свою функцию), выход за границы массива,
дробные и отрицательные операнды, восстановление после мусорного ввода.
Поведение при делении на ноль зафиксировано тестом как есть: результат
`inf`, а не сообщение об ошибке.
