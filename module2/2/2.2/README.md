# 2.2 — Калькулятор на switch

Консольный калькулятор с четырьмя операциями. Пункт меню выбирает операцию
через `switch`.

## Сборка и запуск

```
make
./calc.exe
```

## Файлы

| Файл | Назначение |
|---|---|
| `calc.h` | Прототипы операций и меню |
| `calc.c` | Операции и цикл интерфейса |
| `main.c` | Точка входа, настройка кодировки консоли |
| `tests/` | Юнит-тесты на Unity |

## Как устроено

Каждая операция — отдельная `static`-функция вида `double f(double, double)`.
`interface_calc` читает пункт меню и два числа через `scanf`, диспетчеризация
идёт по `switch`.

Разбор ввода устроен так: если `scanf` вернул не то количество полей, остаток
строки дочитывается циклом `getchar` до `\n`, и меню повторяется. Без этого
нечисловой ввод зациклил бы программу — `scanf` не сдвигает позицию чтения,
если разбор не удался.

Деление на ноль проверяется в меню, а не в `divide`: сама функция вернула бы
бесконечность по IEEE-754.

| Пункт | Операция |
|---|---|
| 1 | Сложение |
| 2 | Вычитание |
| 3 | Умножение |
| 4 | Деление |
| 0 | Выход |

## Примеры работы

### Обычное вычисление

```
Калькулятор:
1) +
2) -
3) *
4) /
0)Выход

Выбор: 1
Введите два числа: 5 3
Результат сложения: 8
```

Числа вводятся через пробел одной строкой, дробные — через точку:
`0.5 0.25` даст `Результат сложения: 0.75`.

### Ошибки ввода

```
Выбор: 4
Введите два числа: 7 0
Деление на ноль

Выбор: abc
Введите число

Выбор: 3
Введите два числа: 2.5 4
Результат умножения: 10
```

Деление на ноль отвергается до вызова операции, нечисловой пункт меню не
зацикливает программу — остаток строки дочитывается, и меню повторяется.
Оба сообщения идут в `stderr`, поэтому при перенаправлении вывода в файл они
останутся на экране.

## Тесты

```
cd tests
make test
```

Операции объявлены `static`, поэтому тест включает `calc.c` целиком.
`stdin` подменяется файлом-фикстурой, `stdout` перехватывается в файл и
проверяется на нужные подстроки, отчёт Unity уводится в `stderr`.

Покрыты: арифметика всех четырёх операций (включая ноль, дроби, отрицательные,
деление на ноль и `0/0`), вывод меню на каждой итерации, разбор корректного и
мусорного ввода, восстановление после нечислового ввода, отказ на неизвестном
пункте меню.

Один тест помечен `TEST_IGNORE`: на EOF `interface_calc` зацикливается —
`scanf` возвращает `EOF`, цикл дочитывания упирается в тот же `EOF`, и выхода
из цикла нет. Поэтому все остальные тесты завершают ввод пунктом `0`.
