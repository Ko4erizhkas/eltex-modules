# 6.2 — Телефонная книга с динамической библиотекой

Продолжение 6.1: та же библиотека списка собирается разделяемой —
`libphonebook.dll` на Windows, `libphonebook.so` на Linux.

## Сборка и запуск

```
make
./pb.exe
```

## Файлы

Исходники побайтово те же, что в 6.1 — `phoneBook.h`, `phoneBook.c`,
`menu.h`, `menu.c`, `main.c`. Отличается только `Makefile`.

В этом и смысл задания: граница библиотеки проведена ещё в 6.1, а статическая
она или динамическая — решает сборка, а не код.

## Что меняется в сборке

| | Windows | Linux |
|---|---|---|
| Файл библиотеки | `libphonebook.dll` + `libphonebook.dll.a` | `libphonebook.so` |
| Компиляция | как обычно | `-fPIC` |
| Компоновка библиотеки | `-shared -Wl,--out-implib,libphonebook.dll.a` | `-shared` |
| Компоновка программы | `-L. -lphonebook` | `-L. -lphonebook -Wl,-rpath,.` |

`Makefile` выбирает ветку по переменной `OS`, которую Windows выставляет
в `Windows_NT`.

- `-fPIC` нужен потому, что разделяемая библиотека грузится по произвольному
  адресу, и код в ней не может рассчитывать на фиксированные адреса.
- `--out-implib` создаёт библиотеку импорта: программа линкуется с ней, а сам
  код остаётся в DLL.
- `-rpath,.` записывает в exe путь поиска библиотеки; без него на Linux
  понадобится `LD_LIBRARY_PATH=.`.

Экспорт символов явно не размечен: и MinGW, и ELF по умолчанию экспортируют
все внешние функции.

## Чем это отличается от 6.1 при запуске

Код библиотеки в exe больше не попадает — он остаётся в отдельном файле и
подгружается при запуске. Если удалить `libphonebook.dll`, программа не
стартует; в 6.1 после удаления `libphonebook.a` она работала как ни в чём
не бывало.

Windows ищет DLL рядом с исполняемым файлом, поэтому библиотека должна лежать
в одном каталоге с `pb.exe`.

## Примеры работы

### Добавление контакта

```
1. Добавить контакт
2. Удалить контакт
3. Изменить контакт
4. Вывести все контакты
0. Выйти
Выберите действие: 1

Введите Ф.И.О
Фамилия - обязательно: Яковлев

Имя - обязательно: Никита

Отчество:
Введите номер телефона #1 (пусто - завершить) (максимум 4 номера): +7-901-555-11-22
Введите номер телефона #2 (пусто - завершить) (максимум 4 номера):
Соцсеть #1 - платформа (пусто - завершить):
```

Отчество можно не вводить — пустая строка превращается в `-`. Контакт встал
в хвост списка: «Яковлев» больше всех тестовых фамилий.

### Правка Ф.И.О. и переезд по списку

```
Выберите действие: 3

-------------------
Список контактов:
... вывод всех контактов ...

-------------------
Выберите контакт: 9

Список доступных изменений:
1. Изменить Ф.И.О
2. Изменить соц сети
3. Удалить соц сети
4. Изменить номер телефона
5. Удалить номер телефона
Выберите действие 1

Измениние Ф.И.О (пусто - оставить без изменений)
Имя [Никита]:
Фамилия [Яковлев]: Андреев
Отчество [-]:
```

После смены фамилии контакт переезжает из хвоста в голову: меню вызывает
`phlist_reposition` из библиотеки, которая отцепляет узел и вставляет его на
новое место. Проверить можно пунктом 4.

## Тесты

```
cd tests
make test
```

Набор тестов тот же, что в 6.1, но линкуется с разделяемой библиотекой —
проверяется и то, что она собралась, и то, что программа с ней запускается.
На Windows `Makefile` перед прогоном копирует DLL в каталог тестов: иначе
`run_tests.exe` её не найдёт. На Linux ту же задачу решает `-rpath,..`.
