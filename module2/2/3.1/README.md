# 3.1 — Маска прав доступа к файлу

Программа показывает права доступа в трёх видах сразу — буквенном, цифровом
и битовом — и умеет менять их chmod-выражениями, не трогая сам файл.

## Сборка и запуск

```
make
./chmod_m.exe
```

## Файлы

| Файл | Назначение |
|---|---|
| `perm.h` | Тип `Perm`, константы битов, API |
| `perm.c` | Разбор, вывод, chmod-выражения, меню |
| `main.c` | Точка входа, настройка кодировки консоли |
| `tests/` | Юнит-тесты на Unity |

## Меню

| Пункт | Действие |
|---|---|
| 1 | Ввести права буквами (`rw-r--r--`) или цифрами (`644`, `0755`) |
| 2 | Взять права у файла через `stat` |
| 3 | Изменить текущие права: `u+x`, `go-w`, `a=rw`, `o+t`, `644` |
| 4 | Показать текущие права |
| 0 | Выход |

Права хранятся в одной переменной `Perm`, поэтому пункт 3 работает поверх
того, что задали пункты 1 или 2.

## Представления

```
Буквенно: -rwxr-sr-x
Цифрами:  2755
Битами:   010 111 101 101
          спец u   g   o
```

Битов двенадцать, а не девять: старшая тройка — setuid, setgid, sticky.
Без неё `2755` и `0755` в двоичном виде выглядели бы одинаково. В буквенной
форме те же биты дают `s`/`S` и `t`/`T` — заглавная буква означает, что
специальный бит стоит, а бита `x` под ним нет.

Буквенную строку можно вводить и длиной 10 — первый символ считается типом
файла, чтобы строку можно было скопировать прямо из вывода `ls -l`.

## chmod-выражения

Клаузы через запятую, в клаузе `[ugoa...]` и один или несколько операторов
`+ - =` с правами `rwxXst` либо копированием класса (`g+u`). Пустой класс
означает `a`; umask не учитывается, потому что права всё равно не применяются
к файлу. `X` ставит `x` только у каталога или если бит `x` уже где-то стоит.
`=` очищает права своего класса вместе с его специальным битом. Числовая
форма (`644`) заменяет права целиком.

## stat и сравнение с ls -l

На Linux используется `lstat` — как и `ls -l`, чтобы симлинк не
разыменовывался; на Windows `lstat` нет, берётся `stat`.

Сверять вывод с `ls -l` имеет смысл только на Linux: под Windows CRT кладёт
в `st_mode` лишь флаг «только чтение» и копирует биты владельца в группу и
остальных, поэтому там всегда получается `0666`, `0444` или `0777`.

## Тесты

```
cd tests
make test
```

Весь API `perm.c` публичный, поэтому файл линкуется как обычно, включать `.c`
в тест не требуется.

Покрыты: все три преобразования (включая специальные биты и заглавные
`S`/`T`), разбор восьмеричной и буквенной записи вместе с отказами на мусоре,
взаимная обратимость разбора и вывода, chmod-выражения (`+`, `-`, `=`,
несколько клауз, несколько операторов в клаузе, копирование класса, `X` для
файла и каталога, специальные биты), чтение прав файла и каталога, отказ на
несуществующем файле, а также меню целиком — через подмену `stdin` и перехват
`stdout`.
