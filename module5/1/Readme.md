### Задание 1 модуля 5
## Описание задания: Написать модуль ядра Hello World для своей версии ядра. Поменять описание модуля, добавить себя как автора и придумать свою лицензию.



# Демонстрация запуска

**Исходник находится по пути ../module5/1/hello.c**

**Сборка модуля**
```bash
make
```
![](/module5/1/screenshots/1.png)

**Установка модуля**
```bash
sudo insmod hello.ko
sudo dmesg | tail -1
```
![](/module5/1/screenshots/2.png)

**Извлечение модуля из ядра**
```bash
sudo rmmod hello.ko
```
