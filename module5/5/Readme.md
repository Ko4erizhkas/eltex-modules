### Написать модуль ядра для своей версии ядра, который будет обмениваться информацией с userspace через netlink. 

**Сборка**

Перейти в директорию с исходниками и при необходимости прописать пароль для работы sudo: 
```bash
make
```
**Запуск**
```bash
./user/user5
```
**Удаление**
```bash
make clean 
```
